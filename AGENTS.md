This repository is a TypeScript/npm workspace plus a SwiftPM macOS companion core. `protocol/` is vendor-neutral contract code. `server/`, `bridge/`, and `adapters/core/` depend inward on protocol only; `adapters/fake/` depends on the neutral SDK and protocol and is simulation-only. `server/src/auth/` and `server/migrations/002_auth_identity.sql` contain M08 identity and authorization primitives. `server/src/http/` and migration 003 contain the M09 transport API and durable command acknowledgements; `companion/` contains the Keychain credential vault and native GUI/local bridge. `bridge/src/storage/` contains the M07 SQLite inbox/outbox and recovery primitives. `adapters/cline/` and `extensions/vscode/` implement the explicitly adopted Cline 4.1.22 M19 patch/API boundary; consult its real-host evidence before claiming support. `tests/` holds repository-level smoke, adapter conformance, bridge recovery, and auth checks. Read `IMPLEMENTATION_TRACKER.md` before starting work and implement one milestone at a time.

## Boundaries and security

The existing application executes the LLM. Do not add a replacement runtime, headless executor, private app socket/API or separate model app-server. The user-authorized FastAPI gateway is a public HTTP/SSE facade over the existing TypeScript server, not a new LLM executor. Server-owned transactions, operations/idempotency, credentials/authorization and scheduling remain authoritative; the gateway has no direct database/native access. Native graphical setup/local consent remain required; authenticated API operation is explicitly added. CLI commands remain developer-only. Keep provider formats at the gateway and shared packages vendor-neutral. Bind local services to loopback, authenticate requests and preserve native permissions. Never claim fixture-only or endpoint-shape compatibility as real native/client support.

DECISION-010 supersedes the earlier mandatory native-provider semantic expansion. The server owns API history/instructions, caller-tool validation/IDs/results, service aliases, response lineage and budgets/accounting behind neutral adapters. Server-defined aliases and deterministic versioned token estimates are user-authorized; label source/scope and never claim estimated usage/output quotas as native generation/billing measurements. Cline supplies existing consented I/O/controls; future adapters use the same boundary. Preserve stateful-backend context isolation and native permissions; native activity is not a caller tool call. Reject unsupported options before dispatch. Native SDK generation/tokenizer/strict-decoding changes are not blanket gates; any actual adapter change needs reviewed adoption and fresh affected acceptance. Exact gateway dependencies are locked; M28 adds official SDKs as pinned test consumers, never model executors.

## Code conventions

Keep Swift package code formatted with four-space indentation and public API comments. Pin direct tool/dependency versions and commit lockfile changes whenever manifests change. Preserve requirement IDs and protocol spelling from `requirements.md`.
