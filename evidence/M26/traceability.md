This matrix applies to requirements 2.4 and the exact [frozen candidate](frozen-candidate.json). Earlier native records retain their original versions and consent. A restriction is part of the declared profile; it is never an untested success claim.

[Root regression](root-test.log): 182 passed, zero skipped. [Gateway regression](gateway-test.log): 54 passed. [Swift](swift-test.log): 8 passed. The gateway SDKs consume APIs; Cline executes the model.

## Performance and soak proof

[Performance](performance.json) records raw nearest-rank distributions for three healthy local trials and a separate 10 MiB stalled-outbox trial, excluding model runtime. Actual native approval visibility is measured from bridge-observed event timestamp to public HTTPS SSE arrival on the same Mac; both current samples are below one second. Model generation is excluded from that interval.

The interrupted [first bridge soak](soak-attempt-1.json) and [log](soak-attempt-1.log) ended on the deliberate disposable PostgreSQL restart, so they are not a soak pass. [Preliminary native monitor](deployed-soak.json) records expected takeover/restart outages and is also not a pass. Replacement [bridge soak](soak.json), final [real native idle/active soak](real-native-soak.json) and independent [deployment/lease monitor](final-deployed-monitor.json) each completed its actual hour with no failures. These are single local host observations, not long-term uptime guarantees.
