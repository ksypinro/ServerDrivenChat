# Qualification evidence in the source repository

This directory preserves milestone narratives and exact artifact manifests.
Raw local execution reports, screenshots, logs, transcripts, signatures and generated
native workspaces are intentionally ignored by Git. Links to those raw records in
historical documentation require the original local qualification archive.

See [source distribution notes](../docs/source-distribution.md) for the inclusion
policy and fresh-checkout limitations. These records describe past runs on exact
pins; they do not establish acceptance for a new build or host.
