# Experimental Cline registration extension

This package exposes `sdcBackendDriver` to a reviewed generic-host loader. It wraps
the existing app-owned Cline API 1.3 and checks the retained Cline 4.1.2204 native
fingerprints before obtaining the native export. The host independently verifies
its complete catalog artifact set; these two entry checks are not full provenance.

The host's production catalog is empty. Installing this candidate does not qualify
or enable native control. A separately reviewed evaluation procedure, exact package
acceptance and fresh graphical consent are still required. No native conversation
is created and no model starts through discovery or factory construction.

Use only an isolated VS Code installation containing the reviewed maintained Cline
package. This extension declares Cline's original ID as a dependency; installing it
without the maintained package may let VS Code offer stock Marketplace Cline, which
this driver rejects. Do not replace the accepted companion or ordinary editor.
