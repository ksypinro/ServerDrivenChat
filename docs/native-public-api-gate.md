## Declared connection profile

- Text and committed PNG/JPEG are submitted to an explicitly consented task with revision, binding, lease and live caller-authority fences.
- Native approval/question/cancel controls address actual pending native identities. A durable server receipt remains distinct from native acceptance and execution.
- Local input takes over the task and detaches the binding. Graphical reconnection is required after local task/session changes. A selected historical task must be resumed before native submission.
- Server conversations use a dedicated consented binding or explicitly selected shared-task context. Server composition does not erase hidden native history or claim provider-privileged roles.
- Usage and output quotas follow the labeled `sdc-text-v1` estimate. Hidden native context, reasoning, billing and generated-token limits remain unknown.
- Mutable native output is collected into an immutable terminal result before provider-shaped text deltas can be published.
- Caller tools are parsed and validated by the server for caller execution, but the native binding must first have reviewed effect-safety evidence. The present native tool profile is withheld; requests fail before dispatch. Prompt instructions alone do not qualify it.
- Sampling, exact vendor accounting, built-in provider tools and other unsupported stronger semantics are rejected before dispatch.
